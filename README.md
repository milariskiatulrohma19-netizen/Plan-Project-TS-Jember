# PLAN & ACTION TS JEMBER

Website HTML siap dipublikasikan menggunakan GitHub Pages.

## Cara publish
1. Buat repository baru di GitHub.
2. Upload `index.html` ke root repository.
3. Buka **Settings → Pages**.
4. Pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Klik **Save**.
7. Setelah deployment selesai, buka URL GitHub Pages yang diberikan.

Catatan: website ini menyimpan data tabel menggunakan `localStorage`, sehingga data tiap browser/user terpisah. Untuk database bersama antar-user diperlukan backend/database online.
